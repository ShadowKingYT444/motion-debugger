# Author and review the user's motion

Use this namespaced entry when another installed kit provides `/motion`. Preserve the existing design and public interactions. Read the Motion Debugger transition authoring reference and use the shipped persistent handoff, staged decomposition or drag release pattern only when it suits the brief. The browser-safe patterns reuse the existing spring engine; the consumer owns objects, assets, materials, camera and its render loop.

In a project skill installation, references and recipes are included in this folder: read `references/transition-authoring.md` and `recipes/transition-patterns.mjs`. In the native plugin package, read [the authoring reference](../motion/references/transition-authoring.md), [bindings](../motion/recipes/transition-bindings.mjs), and [patterns](../motion/recipes/transition-patterns.mjs). Connected hosts can fetch those exact sources with `motion_recipe({id:"kinetic-field"})`.

Derive a transition plan from the normal brief: stable actor identities and renderer bindings, source locations, protected attributes, acyclic phase dependencies, coordinate units, clock, input policy, meaningful completion and reduced motion. Freeze protected file hashes before edits. Author up to three candidates including the current version under one measured budget. Fix functional failures first. Review a short native journey, interruption/reversal and actual frame evidence before choosing by motion meaning, response, trackability and visual preference separately. Cite capture IDs, events and delivered frame hashes, or abstain and retain the last verified source checkpoint. Pose preview is only an authoring aid; it establishes no interaction latency or FPS claim.

Use `motion_review` when connected, or the existing capture/inspect/frames tools. Verify native pixels, desktop/mobile composition, reduced motion, pause/replay and useful final state. Scene annotations remain app-reported hints. Missing evidence remains unverified. Keep successful actor bindings, plan, regression journey, measured costs and protected hashes with the app; do not save an unfiltered full-page style library.
