# LOOP paired generation and independent verification

Two fresh native Codex sessions receive the [same brief](BRIEF.md), reference observations, local Three 0.186.1 assets, Playwright 1.63.0 dependencies and ordinary coding/browser tools. The treatment prompt adds `$motion`; its project receives five complete skills and a fresh installed 0.5.0 MCP runtime. Initial application inputs have identical hashes. Each session has thirty minutes, with the final six minutes reserved in the brief for verification. There is no model override: the configured CLI settings and actual execution logs are recorded; provider-wire model identity is unavailable.

The [protocol](PROTOCOL.json) records native CLI version, start/deadline/exit times, permission mode, dependency lock and candidate package hashes. An immutable audited transport forwards the assisted session's native MCP messages and preserves exact app source before and after each tool call. Its I/O overhead counts within the assisted session's wall budget. This records source at both call boundaries; matching digests do not detect edits made and reverted within a call. It does not claim timing-neutral instrumentation. Raw requests, responses, native images, failed captures and execution events are retained locally. No candidate repairs are made by the parent or reviewer during generation or after the endpoint freeze.

Sources are frozen unchanged under `source/ordinary` and `source/motion`. The manifests cover every retained regular application input by SHA256 and byte size. Dependency links, agent configuration/skills, generated media/logs and build directories are excluded from the application digest; installed intervention inputs and logs are recorded separately. Actual source modification times beyond the deadline are reported. A time-limited process without a final response stays time-limited, rather than becoming a completed agent run.

The [held-out protocol](HELDOUT-PROTOCOL.md) was written before candidate inspection. Timestamped [reduced-motion](HELDOUT-AMENDMENT.json) and [scrub-release](HELDOUT-AMENDMENT-SCRUB.json) clarifications also precede inspection. The independent reviewer can map semantic controls after freeze, but cannot alter source or weaken the shared user expectations. Each verifier execution first archives the exact harness, configuration and source/runtime identities. Failed attempts remain intact; a corrected verifier creates another attempt. The reviewer uses normal native pointer and keyboard inputs, held forward/backward scrubbing, rapid style switching, pause/resume/replay, modal focus and actual SVG/JSON downloads. Desktop, mobile, reduced motion and unavailable WebGL are separate conditions.

Complete full-viewport films begin before navigation. Corner calibration checks framing independently; screenshots are taken in separate nonrecording contexts. Lossless pause pixels, rendered pose, UI state, exports and native input traces provide distinct evidence. Internal scene counters are supplementary annotations. Decoded recording frames have approximate time alignment, and lossy codec differences alone are not pause defects. Software-rendered headless Chrome and a single paired generation trial cannot establish physical-device performance, general agent superiority or a causal plugin effect. Functional completion, visible quality and temporal evidence are reported separately.

The paired trial uses its immutable initial package. Subsequent library fixes for callback pause/recovery, paused selection and exploratory deadlines have separate exact-source browser proofs and final package verification. They are not substituted into the frozen comparison endpoints. Other verification jobs shared the host during generation; its CPU environment was not exclusive.

Its first capture retained an over-budget interaction failure; another capture found an ambiguous Orbit selector. Later positive outcomes passed after that selector was repaired. Both before/after comparisons remained inconclusive because finite temporal evidence/trajectory integrity was inadequate. The real tool responses do not establish a smoothness improvement or prove model visual inspection.
