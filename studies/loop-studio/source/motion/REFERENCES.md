# LOOP reference observations

Reviewed 2026-10-04. References inform an original identity; no vendor artwork is distributed.

- [Lusion](https://lusion.co/): actually inspected the live page and two browser views. A large specimen occupies most of the hero, with cobalt, black and ivory sculptural forms, contrasting matte/gloss materials and directional lighting. Scrolling changes framing while a compact navigation remains visible. The useful principle is making the specimen carry the identity; a screenshot alone does not establish its cadence.
- [Rive use cases](https://www.rive.app/use-cases): the official examples connect interactive animation to useful interface state, including creator tools. The useful principle is that editing controls, meaningful poses and the final artifact belong to the same task. Only documentation was reviewed; no native Rive runtime or licensed animation is included.

LOOP is an original fictional identity studio. Pulse, Weave and Orbit are creative brief constraints, not borrowed assets or supplied animation algorithms. Both agents receive the same references and normal browser access.
