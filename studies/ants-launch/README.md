# Anthropic Ants: ordinary and Motion workflows

Two actual Codex sessions built this unofficial launch-page concept from the [same brief](BRIEF.md), with the same configured model, original assets, browser references, dependencies and twenty-minute wall budget. Both kept normal browser tools. Only the assisted arm received the freshly installed Motion skills/MCP and `$motion` prefix. Both reached the time limit; their unchanged source endpoints are preserved.

Both deliver original lit, articulated 3D ants, scroll-driven composition, four-stage task choreography and a useful repair-cafe plan. Independent browser checks cover desktop, mobile, keyboard, pause/resume, cancellation/replay, reduced motion and WebGL fallback. Complete recordings and exact source/runtime hashes accompany the [results](RESULTS.md). Temporal and pixel-measurement limitations remain; **this pair does not prove an overall plugin or smoothness advantage**.

From the repository root:

```sh
npm ci
npm run demo:ants
```

Open the printed loopback URL. Interact with each page, switch to 390px width, use fullscreen and watch complete native recordings. No builds or source repairs are performed by the viewer. Source manifests and allowlisted recording bytes are verified before serving; failed verification remains unavailable.

The [method](METHOD.md), [protocol](PROTOCOL.json), [actual tool-use summary](TOOL-USE.json), [reference observations](REFERENCES.md) and [machine-readable evidence](RESULTS.json) distinguish workflow use, functional completion, visual review and temporal evidence. Original missing Ants artifacts were not reconstructed or passed off as recovered originals. Earlier failed attempts, verifier mistakes and codec limitations remain retained. Vendor artwork was not copied; see [third-party notices](THIRD-PARTY-NOTICES.txt) for the shared Three.js runtime.

Motion's tested contribution in this trial is actual discovery/use of shipped spring and drawer recipes and capture/inspection tools. The ordinary workflow also found and repaired elapsed-time task progress. Tools used during evolving source do not automatically establish a source-bound final comparison, causal superiority or model visual inspection. The release candidate adds refined colony, drawer-focus and elapsed-sequence modules separately, with separate native browser verification.
