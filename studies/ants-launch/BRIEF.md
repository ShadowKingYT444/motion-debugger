# Shared ordinary design prompt

Build a beautiful, fully working launch-page concept for **Anthropic Ants**, a coordinated colony of small helpful agents. This is an unofficial design concept, not an announced Anthropic product. Make it feel like a crafted product launch, with confident editorial typography, a warm ivory/charcoal/vermillion palette, generous composition, and a memorable, richly rendered interactive 3D ant colony. Author original assets; do not copy vendor illustrations or invent product claims.

Use the headline “Small agents. Extraordinary together.” Explain assignment → parallel work → coordinated handoff → a useful finished artifact through one purposeful visual story. The ants should have recognizable articulated bodies, convincing materials, depth, lighting, grounded shadows, and coordinated movement. Include a scroll-driven transition into a closer view of the work, responsive interaction details, and smooth rapid reversal rather than disconnected floating cards or a rotating placeholder.

Visitors can launch a fixed example task, see four stages of work complete, read the resulting plan, pause/resume, cancel, and replay. Provide a real details drawer with Escape and keyboard operation. Controls and scene must reflect the same application state. Reduced motion retains the complete task and a useful composed scene without decorative loops or camera travel. Include a meaningful fallback for unavailable WebGL. Mobile should feel designed, not squeezed.

Use the provided local Three.js installation and vanilla HTML/CSS/JavaScript. Keep all assets local. Build and refine using your normal coding and browser tools. Inspect the actual moving result and test the full visitor journey, every advertised control, keyboard, mobile, and reduced motion before finishing. Deliver runnable source, a concise execution record, and candid remaining limitations.

Reference direction: the official Opus 5.5 launch’s immersive composition and editorial clarity, and Grok Bot’s purposeful animated demonstration. Interpret those principles in an original Ants identity.

Budget: twenty minutes total, including final verification; reserve the last four minutes for testing and delivery. Both arms receive this exact brief, dependencies and references. The treatment prompt adds only `$motion` at the beginning.
